よく使われる言い換え表現

なろう・カクヨム作家向けの言い換え表現辞典です。小説執筆でよく使われる単語のビフォー→アフター例文を収録しています。

「悲しい」の言い換え表現

悲しかった → 断腸の思いで唇をかんだ
悲しかった → 瞳の奥で何かが静かに崩れた
悲しかった → 胸の奥底に鉛を飲み込んだような重さが広がった

「雨が降った」の言い換え表現

雨が降った → 氷雨がひとりぼっちの背中を濡らした
雨が降った → 雨粒が窓を叩く音だけが静寂を破っていた
雨が降った → 空が泣いているような、細い雨が降り続いていた

「嬉しい」の言い換え表現

嬉しかった → 胸の奥で何かが弾けるように温かくなった
嬉しかった → 心が羽ばたくような軽さに包まれた
嬉しかった → 頬が自然と緩み、指先まで喜びが満ちていくようだった

「走る」の言い換え表現

走った → 足が地面を蹴るたびに風が頬を切り裂いた
走った → 息を切らしながら、ただ前だけを見て駆け続けた
走った → 心臓が爆発しそうなほど激しく鼓動を打ちながら走り続けた

「震える」の言い換え表現

震えた → 恐怖で膝ががくがくと笑い、立っていることすら難しかった
震えた → 指先が細かく震え、握りしめた拳が白くなった
震えた → 全身の毛が逆立ち、背筋を冷たいものが走り抜けた

「笑う」の言い換え表現

笑った → こらえきれずに声が漏れ、肩が小刻みに揺れた
笑った → 口角が自然と上がり、目尻に柔らかな皺が寄った
笑った → 声を上げて笑い続けた。久しぶりに心から笑えた気がした

他にも「好き」「泣く」「孤独」「怒り」など100語以上収録しています
